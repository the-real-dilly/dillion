DILLYVERSE — An original 3D voxel sandbox survival game built with Three.js WebGL 2, custom chunk meshing with ambient occlusion, procedural textures, Web Audio synthesis, IndexedDB world persistence, and a real Node.js WebSocket multiplayer server.

Controls: WASD Move · Space Jump (2× Fly in Creative) · Shift Sprint · Ctrl Crouch · LMB Mine/Attack · RMB Place/Use · E Inventory · Q Drop · T Chat · Esc Pause

# Dillion

"The daily landing": seven prompts a day, rare answers launch you farther from Earth. Static site (no build step).
Includes a mini crossword, Orbit Scramble, Rover Rescue, Memory Match and Higher or Lower, a daily mission twist, and a starship that launches in the background. Open `index.html` or run `python3 -m http.server`. An original Mars-themed take on the daily-prompt game format, with a parody pixel Elon who pops out of a crater.
